# Security Policy

## Supported Versions

Only the latest version of ASCEND is currently supported with security updates.


## Reporting a Vulnerability

If you discover a security vulnerability in ASCEND, please report it privately to the project maintainer.

You may report issues through GitHub's [Private Vulnerability Reporting](https://github.com/kalabasaa/Ascend/security/advisories/new), if enabled for this repository.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Screenshots or other supporting evidence, if available.

## Response Process

The maintainer will review the report, investigate the issue, and determine the appropriate fix.

Please avoid publicly disclosing security vulnerabilities until they have been reviewed and addressed.

## Scope

This policy covers security vulnerabilities related to the ASCEND application, including authentication, authorization, data handling, database access, and other application-related security concerns.
