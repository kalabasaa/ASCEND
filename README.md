## About

Ascend is a gym management system developed to help organize and manage gym operations through a centralized web application. The project focuses on providing a structured way to handle gym-related information while improving the overall management process.

The project is currently under development.

## Features

- **Gym Management** – Centralized management of gym-related information.
- **Membership Management** – Organize and manage gym memberships and subscriptions.
- **Attendance Tracking** – Daily check-in log with streak tracking, similar to a GitHub contribution graph.
- **Administrative Interface** – Provide a centralized interface for managing gym operations, sales, and users.

*Features are currently under development and may change throughout the project.*

## Commit Convention

Reference for commit message prefixes used in this project.

| Type | When to use it |
|---|---|
| `feat` | Add a new feature |
| `bugfix` | Fix a bug |
| `refactor` | Improve code without changing behavior |
| `docs` | Documentation changes |
| `chore` | Maintenance tasks |
| `style` | Formatting only, no logic changes |
| `test` | Add or update tests |
| `build` | Build system or dependency configuration |
| `hotfix` | Urgent fix for a production issue |
| `perf` | Improve performance |
| `revert` | Undo a previous commit |
